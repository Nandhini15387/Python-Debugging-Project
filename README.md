# Student Grade Calculator

## Project Overview

The Student Grade Calculator is a Python-based application developed as part of the Week 2 internship task on Debugging and Troubleshooting.

The application accepts student marks, calculates the average, and assigns a grade based on the calculated average.

## Features

* Accepts student name and marks.
* Calculates average marks.
* Assigns grades automatically.
* Validates marks between 0 and 100.
* Handles invalid numerical inputs.
* Uses exception handling to prevent unexpected crashes.

## Technologies Used

* Python
* Visual Studio Code
* Git and GitHub

## Error Handling

The project involved identifying and correcting:

1. TypeError
2. IndentationError
3. NameError
4. ValueError

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```
